# Delivery App

A web application where users can browse shops, add items to cart, and place food delivery orders.

- Live Demo:
- Repository:

## Accomplished Level

Middle Level (Base + partial Middle)

### Base Level

- Shops page with shop listing and product browsing
- Add products to cart
- Shopping cart page with product management (change quantity, remove items)
- Order form with email, phone, and address fields
- Form validation before submission
- Order saved to database on submit

### Middle Level

- Responsive design — desktop, tablet, and mobile
- Product sorting (by price ascending/descending, alphabetically A→Z)
- Shop filtering by rating range

## Tech Stack

Frontend:

- React 19 + TypeScript
- Vite
- Tailwind CSS v4
- React Router DOM
- React Hook Form + Zod
- Axios

Backend:

- NestJS + TypeScript
- Prisma ORM
- PostgreSQL
- REST API
- class-validator + class-transformer
